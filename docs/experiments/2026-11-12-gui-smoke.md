### Failures found and fixed
1. **Suggest three tasks failed for every agent (#34).** `proposeTasks` built `<base>/../home-proposal`; Tauri's fs plugin rejects any path containing `..`. Node tests could not catch it.
2. **Every Codex A/B run failed (#35).** Codex skill enumeration walks up from run dirs looking for `.git` and probed `~/Library/Application Support/.git`, outside the `lstat` scope.

Both showed only the generic run error in the UI; the cause was found by temporarily logging the raw error in dev mode (not committed).
