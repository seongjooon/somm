# somm MVP Implementation Plan

> **For agentic workers:** 이 계획은 AGENTS.md의 Multi-agent/Tooling 규칙으로 실행한다. superpowers subagent-driven-development나 executing-plans의 서브에이전트 실행은 쓰지 않는다. 리드가 태스크 하나마다 Paseo handoff로 Codex 구현자 하나를 띄운다(워크스페이스 = worktree = 브랜치 하나, base `origin/main`). 단계는 체크박스(`- [ ]`)로 추적한다.

**Goal:** 스킬 스토어 → 정적 보안 검사 → Lite 샌드박스 A/B → 결과 → Claude Code·Codex 설치 관리를, 같은 엔진 위의 CLI(`somm`)와 macOS 데스크톱 앱으로 제공한다.

**Architecture:** pnpm 워크스페이스. `packages/core`(순수 TS 엔진)가 모든 로직을 갖고, 파일·프로세스·DB는 `platform/` 인터페이스로 주입받는다. `apps/cli`는 Node 구현(`@somm/core/node`)을, `apps/desktop`은 Tauri 구현(plugin-fs, plugin-sql, Rust 화이트리스트 실행)을 주입하고 표시만 한다. core 기능은 CLI로 먼저 검증하고 GUI를 그 위에 얹는다.

**Tech Stack:** pnpm workspace, TypeScript, Node `node:sqlite`·`node:util parseArgs`, esbuild(CLI 번들), Tauri 2, Svelte 5(Vite, SvelteKit 아님), Tailwind CSS v4, tauri-plugin-{shell,fs,sql,dialog}, `yaml`, Vitest.

**Spec:** `docs/superpowers/specs/2026-11-06-somm-mvp-design.md` (구현자는 계획과 함께 반드시 읽는다)

## Global Constraints

- 파일당 ~300줄 이하. 큰 UI 라이브러리 금지. **새 의존성은 Task 2에서만** 추가한다.
- `packages/core`는 `@tauri-apps/*`, Svelte, `node:*`를 import하지 않는다(단 `src/node/**`는 `node:*` 허용). 의존 방향은 `apps/* → core`만.
- somm은 로그인 정보와 토큰을 읽지도, 저장하지도, 중계하지도 않는다. Isolated API 키는 메모리(GUI) 또는 환경 변수(CLI)에서만 오고 자식 프로세스 env로만 넘긴다. DB·로그·이벤트 저장분에 남기지 않는다.
- Subscription 실행 env에서는 `ANTHROPIC_API_KEY`, `CODEX_API_KEY`를 **제거**한다.
- 사용자 저장소에 `git worktree add`를 쓰지 않는다. 사용자 `~/.claude`, `~/.agents`, `~/.codex`에는 설치·삭제·끄기에서만, 백업 후에 쓴다.
- 데이터 폴더: `SOMM_DATA_DIR` ?? `~/Library/Application Support/io.github.seongjooon.somm`. GUI·CLI 공유. Tauri identifier = `io.github.seongjooon.somm`.
- 등급 `'A'|'B'|'C'|'D'|'F'`. 정적 검사는 A~D만, F는 동적 확정 증거(canary)만. 설치: A·B 바로 설치, C·D 테스트 또는 경고 확인 후, F 차단.
- 판정 문구: 추천 `// somm: pairs well`, 조건부 `// somm: needs to breathe`, 비추천 또는 F `// somm: corked`.
- CLI 사람용 출력 첫 줄은 `// somm: ...`. `--json`이면 JSON 하나만(`"somm"` 필드에 같은 문구). 종료 코드 0/1/2(2 = corked 또는 F).
- UI 문자열은 i18n 키(공통 `apps/desktop/src/i18n/`, 기능 `apps/desktop/src/features/<name>/i18n.{en,ko}.json`). CLI는 영어.
- 경로에 공백과 한글이 있어도 동작해야 한다.
- 커밋: Conventional Commits, 영어, 한 커밋에 한 type.

## Review Focus

1. **공백·한글 경로의 프로젝트** → 복사, git, CLI 실행이 정상이어야 한다. (T7 `handles paths with spaces and Korean`)
2. **CLI 미설치·미로그인** → 무한 대기 없이 "Not installed / Not logged in"과 안내. (T4 `detect reports not-logged-in`, T8 `runAB surfaces auth error`, T10 `test exits 1 with login hint`)
3. **실행 중 취소(Ctrl-C, 앱 종료)** → 두 arm 프로세스 종료 + `runs/<id>` 정리. (T8 `abort kills arms and cleans up`, T10 `SIGINT aborts run`)
4. **같은 이름 스킬이 이미 설치됨** → 덮어쓰기 확인 없이는 거부, 확인 시 백업 후 교체. (T4 `install refuses existing without overwrite`, T10 `install without --force exits 1`)
5. **lockfile이 HEAD와 다른 프로젝트** → 의존성 복제 대신 재설치로 전환하고 경고. (T7 `falls back to install when lockfile drifted`)

1. 읽을 것: `AGENTS.md`, 스펙, 이 계획의 해당 태스크. 다른 태스크는 Interfaces만.

5. 리드가 `/paseo-advisor` 1회 검수(읽기 전용) → 수정 → 통과 후 브랜치 push + `gh pr create`.
6. 리드: `origin/main` rebase → 테스트 재실행 → 병합·push → 세션 보관.
