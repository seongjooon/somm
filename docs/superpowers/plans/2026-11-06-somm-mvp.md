# somm MVP Implementation Plan

> **For agentic workers:** 이 계획은 AGENTS.md의 Multi-agent/Tooling 규칙으로 실행한다. superpowers subagent-driven-development나 executing-plans의 서브에이전트 실행은 쓰지 않는다. 리드가 태스크 하나마다 Paseo handoff로 Codex 구현자 하나를 띄운다(워크스페이스 = worktree = 브랜치 하나, base `origin/main`). 단계는 체크박스(`- [ ]`)로 추적한다.

**Goal:** 스킬 스토어 → 상세(정적 보안 검사) → Lite 샌드박스 A/B → 결과 → Claude Code·Codex 설치 관리까지 동작하는 macOS 데스크톱 앱.

**Architecture:** Tauri 2 셸, 로직은 TypeScript. 외부 연동(에이전트 CLI, 출처, 샌드박스)은 `src/adapters/` 인터페이스 뒤에 둔다. 파일·프로세스 접근은 `Fs`/`Proc` 인터페이스로 감싸 Node 구현으로 테스트한다. Rust는 플러그인 등록과 `spawn_agent`/`resolve_bins` 명령만.

**Tech Stack:** Tauri 2, Svelte 5 (Vite, SvelteKit 아님), TypeScript, Tailwind CSS v4, tauri-plugin-{shell,fs,sql,dialog}, SQLite, `yaml`, Vitest, pnpm.

**Spec:** `docs/superpowers/specs/2026-11-06-somm-mvp-design.md` (구현자는 계획과 함께 반드시 읽는다)

## Global Constraints

- 파일당 ~300줄 이하. 기능별 폴더 `src/features/<name>/`. 큰 UI 라이브러리 금지. 새 의존성은 Task 2에서만 추가한다.
- somm은 로그인 정보와 토큰을 읽지도, 저장하지도, 중계하지도 않는다. Isolated API 키는 메모리에만 두고 자식 프로세스 env로만 넘긴다.
- Subscription 실행 env에서는 `ANTHROPIC_API_KEY`, `CODEX_API_KEY`를 **제거**한다(있으면 CLI가 구독 대신 키를 쓴다).
- 사용자 저장소에 `git worktree add`를 쓰지 않는다. 사용자 `~/.claude`, `~/.agents`, `~/.codex`에는 설치·삭제·끄기 동작에서만, 백업 후에 쓴다.
- 모든 앱 데이터는 Tauri `appDataDir` 아래: `somm.db`, `runs/`, `backups/`, `disabled/`, `cache/`.
- UI 문자열은 i18n 키로. 공통 키는 `src/i18n/{en,ko}.json`, 기능 키는 `src/features/<name>/i18n.{en,ko}.json` (병렬 태스크 간 파일 충돌 방지 — 스펙 7절 #18의 세분화).
- 등급은 `'A'|'B'|'C'|'D'|'F'`. [바로 설치]는 A·B만, F는 모든 설치 차단.
- 결과 판정 꼬리말: 추천·조건부 → `// somm: pairs well`, 비추천 또는 F → `// somm: corked`.
- 경로에 공백과 한글이 있어도 동작해야 한다(개발자 경로 자체가 `ai_사업부`).
- 커밋: Conventional Commits, 영어, 한 커밋에 한 type.

## Review Focus

1. **공백·한글 경로의 프로젝트** → 복사, git, CLI 실행이 정상 동작해야 한다. (Task 8 테스트 `handles paths with spaces and Korean`)
2. **CLI 미설치·미로그인·GUI PATH 누락** → 무한 대기 없이 "Not installed / Not logged in" 상태와 안내를 보여야 한다. (Task 4 `detect reports not-logged-in`, Task 9 `runAB surfaces auth error`)
3. **실행 중 취소·앱 종료** → 두 arm 프로세스 종료 + `runs/<id>` 정리. (Task 9 `abort kills arms and cleans up`)
4. **같은 이름 스킬이 이미 설치됨** → 덮어쓰기 확인 없이는 거부, 확인 시 백업 후 교체. (Task 4 `install refuses existing without overwrite`)
5. **Thorough 3회 중 일부 실패** → 성공분으로 요약하고 "신뢰도 낮음 (n/3 성공)" 표시. (Task 9 `summarize with failed iterations`)
